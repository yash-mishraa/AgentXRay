01 / The Combinatorial Challenge

Why manual agent debugging fails at scale.

Modern tool-calling AI agents are guided by composite prompts consisting of system instructions, few-shot examples, dynamic tool schema definitions, user input directives, and runtime environment flags.

The 2N Search Space

When an agent produces an invalid tool call or violates a domain policy, the failure is rarely documented in standard logs. For an agent configuration with N candidate directives or schema parameters, there are 2N possible active subsets. Testing all combinations is computationally intractable even for moderate N.

The Failure of Linear Ablation

Standard developer intuition leans toward linear ablation: disabling directives one by one. This approach requires O(N) full agent runs regardless of fault sparsity. On production LLM APIs, linear scans are prohibitively slow and expensive—and fail completely when multi-element interactions cause the failure.

02 / Algorithmic Lineage

Adapting Andreas Zeller's Delta Debugging.

AgentXRay builds upon the seminal Delta Debugging methodology introduced by Andreas Zeller (2002), adapting it from compiler input reduction to black-box agent intervention search.

01

Binary Subsetting

The candidate pool C is partitioned into n subsets (starting with n = 2). Each subset Δi is evaluated independently. If any partition reproduces the failure, the search zooms into that subset.

02

Complement Testing

If no individual subset Δi reproduces the failure, the algorithm evaluates each complement C \ Δi. If a complement reproduces the failure, the non-offending partition is discarded.

03

Granularity Refinement

If neither subsets nor complements reproduce the failure, the partition granularity increases (n = min(2n, |C|)). On sparse single-fault configurations, this yields logarithmic convergence in O(log N) evaluations.

03 / Causal Rigor

Counterfactual verification & 1-minimality.

Isolation alone does not guarantee causation. AgentXRay proves causality by demonstrating counterfactual necessity.

Formal 1-Minimality

A candidate subset C' ⊆ C is defined as 1-minimal if:

  • C' triggers the failure condition: evaluate(C') = FAILURE.
  • Removing any single element e ∈ C' eliminates the failure: evaluate(C' \ {e}) = SUCCESS.

This guarantees that no irrelevant distractor directives remain in the diagnostic finding.

Empty Set Baseline Verification

AgentXRay additionally tests the empty baseline evaluate(∅). If removing the isolated candidate directive restores clean, successful execution, the condition is counterfactually verified: 

# Counterfactual proof check
assert evaluate([isolated_directive]) == FAILURE
assert evaluate([]) == SUCCESS
04 / Statistical Rigor

Deterministic testbeds vs. live stochastic models.

AgentXRay differentiates between controlled deterministic benchmarks and non-deterministic live LLM interactions.

Deterministic Testbeds ($0.00 Spend)

In offline testbeds and CI regression suites, agent behavior is deterministic (fixed seed or controlled mock agents). The minimizer evaluates each partition exactly once, completing full causal isolation in 2 to 15 milliseconds without network latency or API fees.

Stochastic LLM Sampling

When diagnosing live generative agents (temperature > 0), a single failure or success is insufficient due to stochastic noise. AgentXRay's research framework employs multi-trial binomial sampling:

  • Wilson Score Intervals: Asymmetric confidence intervals calculated over trial success rates.
  • Berger's IUT: Intersection-Union Test for composite statistical hypothesis testing across candidate boundaries.

06 / Scientific Integrity

Operational boundaries & research disclosures.

To maintain scientific transparency and clear engineering expectations:

  • Strict Black-Box Operation: AgentXRay does not analyze neural weights, internal token probability distributions, attention maps, or latent representations.
  • Monotonicity Assumption: Standard ddmin assumes monotonicity (if a subset fails, supersets generally fail). For non-monotonic agents with adversarial cancelation effects, extended complement passes are executed.
  • Evaluation Budget Caps: To protect developers against runaway API expenses, all searches enforce configurable max_evaluations and timeout_seconds limits.
