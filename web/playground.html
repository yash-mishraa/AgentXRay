Simulator Mechanics

The client-side sandbox implements Andreas Zeller's standard ddmin algorithm. It recursively splits the candidate pool into 2 partitions, tests each subset against the trigger condition, increases granularity when subsets pass, and executes an empty set counterfactual check to verify 1-minimality.

Production Integration

In production, evaluations are not simple substring matches: your evaluator callable runs your agent harness, inspects tool call syntax, validates database queries, or queries mock APIs. Use the Python SDK (agentxray.diagnose) or explore the Hugging Face Space for full multi-mechanism evaluations.
