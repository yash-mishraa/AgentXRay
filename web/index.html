Root Cause Attribution

Why Agent Debugging Breaks Down

Observability frameworks log what broke. AgentXRay proves which input condition caused it.

The Naive Approach

Linear Trial-and-Error Scan

When a tool-calling workflow fails, prompts often carry dozens of instructions, schema specifications, and few-shot examples. Standard log analysis reveals that an AST error or tool crash occurred, but cannot identify which directive provoked it.

Developers manually eliminate rules one by one—an $O(N)$ linear pass that wastes hours of engineering time, burns API tokens, and leaves uncertainty over whether removing an instruction actually resolved the underlying conflict.

The AgentXRay Method

Counterfactual Delta Debugging

AgentXRay treats the agent and tools strictly as a black-box system. It partitions the candidate directives into hierarchical subsets and complements, evaluating outcomes with logarithmic efficiency ($O(\log N)$).

When a minimal candidate subset is isolated, AgentXRay performs an explicit counterfactual ablation: proving that removing the candidate restores clean execution (1-minimality).

Minimization Protocol

The 3-Phase Minimization Cycle

01 / INGEST

Candidate Pool & Evaluator

Pass candidate directives (prompts, tool parameters, or flags) and a callable that returns binary pass/fail based on observable tool execution.

02 / PARTITION

Binary Partition Search

Delta Debugging partitions the active candidate pool into subsets and complements, rapidly zooming in on the active failure trigger.

03 / VERIFY

Counterfactual Minimality

AgentXRay evaluates removing the isolated candidate. If removal eliminates the failure, 1-minimality is empirically confirmed.

Scientific Integrity

Truthful Boundaries & Disclosures

Strict Black-Box Boundary

AgentXRay evaluates observable tool-calling inputs and execution outputs only. It has zero access to proprietary model weights, hidden chain-of-thought tokens, or internal activations.

Deterministic vs Stochastic Models

The primary SDK and CLI engine is optimized for reproducible testbeds. Minimizing failures in live non-deterministic LLMs requires multi-trial statistical sampling with Wilson intervals, available via AgentXRay's research benchmark tier.

Integration Contract

AgentXRay does not magically intercept running third-party agents without an evaluator function. Developers provide an evaluator callable or pass declarative scenario specifications.

Zero-Cost Offline Guarantee

All benchmark testbeds and offline CLI demonstrations execute locally with $0.00 commercial API spend, zero network calls, and zero external daemon dependencies.
