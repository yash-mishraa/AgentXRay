Causal Fault Localization

Production agent prompts frequently combine dozens of instructions, schema definitions, and few-shot examples. When an agent emits a malformed tool call, breaks syntax, or violates API contracts, finding which single line caused the break takes hours of manual guessing.

How AgentXRay isolates minimal failure conditions without inspecting model weights or reading private prompts.

AgentXRay partitions the active set into subsets and complements. When a subset reproduces the failure, it zooms in. If not, it increases partition granularity.

Developer Ergonomics

Use it in Python. Or run it from your terminal.

AgentXRay provides two first-class interfaces: a typed Python SDK facade and a developer CLI with strict exit-code contracts for CI/CD pipelines.

Diagnose failures in custom Python agent harnesses by providing candidate directives and a pass/fail evaluator callable. 

from agentxray import diagnose

# 1. Define candidate directives (prompts, tool rules, environment flags)
candidates = [
    "strict_currency: format arithmetic arguments with currency signs (e.g. '$150').",
    "concise_summary: keep final output under 50 words.",
    "markdown_tables: render financial summaries in markdown tables.",
    "formal_tone: use formal business accounting terminology.",
]

# 2. Define evaluator (returns True for failure, False for clean pass)
def my_agent_evaluator(active_subset: tuple[str, ...]) -> bool:
    for directive in active_subset:
        if "strict_currency" in directive:
            return True   # Failure reproduced: syntax error in calculator
    return False          # Clean pass

# 3. Minimize failure condition counterfactually
result = diagnose(
    candidates=candidates,
    evaluator=my_agent_evaluator,
    max_evaluations=20,
    seed=42,
)

print(result.summary)
print(result.is_verified)           # True (1-minimal confirmed)
print(result.isolated_candidates)    # ("strict_currency: ...",)

CLI Process Exit-Code Contract

The CLI adheres to strict exit codes for seamless integration with CI/CD and automation test suites:

Exit Code Category Meaning
0 VERIFIED_CULPRIT / NO_FAILURE Minimal failure-inducing culprit isolated and 1-minimal verified, or clean passing baseline control.
1 INCONCLUSIVE / BUDGET / TIMEOUT Search halted without proving 1-minimality, evaluation budget was exhausted, or timeout was exceeded.
2 Argument / Schema Error Invalid CLI arguments, non-existent scenario file, malformed JSON, duplicate candidates, or schema failure.
3 ERROR Evaluator raised an unexpected runtime exception or infrastructure failure during execution.

Python SDK Evaluator Contract

The evaluator callable passed to diagnose(candidates=..., evaluator=...) receives the currently active subset of candidates as tuple[str, ...] and may return:

  • bool: True if the agent failed on this subset; False if it executed cleanly.
  • tuple[bool, str]: (is_failure, diagnostic_message).
  • TargetResult: structured outcome with TargetOutcome.FAILURE or TargetOutcome.SUCCESS.
  • None: signals an inconclusive evaluation (search halts safely without false attribution).

Diagnostic Outcome Statuses

Status Enum is_verified Description
DiagnosticStatus.VERIFIED_CULPRIT True Minimal failure-inducing candidate isolated and verified: removing it restores clean pass.
DiagnosticStatus.NO_FAILURE False The full candidate pool passed cleanly on the baseline check. No failure to minimize.
DiagnosticStatus.INCONCLUSIVE False Evaluator returned inconclusive or search stopped before 1-minimality could be confirmed.
DiagnosticStatus.BUDGET_EXHAUSTED False Target evaluation budget (max_evaluations) was reached before verification.
DiagnosticStatus.TIMEOUT False Wall-clock execution timeout exceeded.
DiagnosticStatus.ERROR False Evaluator threw an unhandled exception or returned an unsupported type.

Truthful Boundaries & Limitations

AgentXRay is engineered with strict epistemic boundaries. Here is exactly what the engine does—and what it does not do.

Strict Black-Box Boundary

AgentXRay observes binary tool calls and execution status only. It has zero access to internal model weights, hidden chain-of-thought tokens, or proprietary system instructions.

Deterministic vs Stochastic Models

The primary SDK/CLI engine is optimized for reproducible testbeds. Minimizing failures in live non-deterministic LLMs requires multi-trial statistical sampling with Wilson intervals, available via AgentXRay's research benchmark tier.

Integration Contract

AgentXRay does not magically intercept running third-party agents without an evaluator function. Developers provide an evaluator callable or run declarative JSON scenario files.

Zero-Cost Offline Guarantee

All demonstration scenarios and offline diagnostics run locally with $0.00 commercial API spend, zero external daemon requirements, and zero remote network requests.
