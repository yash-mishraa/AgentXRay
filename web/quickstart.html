01 / Installation

Install the local development package.

AgentXRay is structured as a standard Python package. Install editable mode from the repository root:

Terminal 
# Clone repository and install in editable development mode
$ git clone https://github.com/yash-mishraa/AgentXRay.git
$ cd AgentXRay
$ pip install -e .

03 / Python SDK Integration

Diagnose custom agents via the Python API.

Import diagnose from agentxray. Pass your candidate directives as a sequence of strings and provide an evaluator callable that tests whether a given candidate subset reproduces the failure.

diagnose_agent.py 
from agentxray import diagnose

# Candidate directives suspected of causing the agent breakdown
candidates = [
    "strict_currency_formatting: format numbers with $ symbol in tool calls",
    "monetary_precision: format all invoices with two decimal places",
    "professional_styling: use formal accounting terminology",
    "audit_trail: annotate calculations with ledger voucher references",
]

# Evaluator function: receives active subset as tuple[str, ...]
# Return True if agent FAILS on this subset, False if it SUCCEEDS cleanly
def my_agent_evaluator(active_subset: tuple[str, ...]) -> bool:
    return any("strict_currency_formatting" in c for c in active_subset)

# Run Delta Debugging search and counterfactual verification
result = diagnose(candidates=candidates, evaluator=my_agent_evaluator)

print(result.summary)
print(f"Verified 1-minimal: {result.is_verified}")
print(f"Isolated directive: {result.isolated_candidates}")
print(f"Evaluations used:   {result.evaluations_used}")
04 / Declarative File Execution

Diagnose reproducible failures from JSON scenarios.

CI pipelines and automated regression harnesses can store candidate directives and offline failure conditions in declarative JSON files, evaluated via agentxray diagnose.

scenario.json 
{
  "name": "currency_ast_scenario",
  "description": "AST arithmetic rejection on currency symbols",
  "candidates": [
    "strict_currency_formatting: format with $ in tool arguments",
    "monetary_precision: format invoices with 2 decimal places",
    "professional_styling: formal terminology",
    "audit_trail: voucher numbers"
  ],
  "failure_condition": {
    "type": "contains_any",
    "patterns": ["strict_currency_formatting"]
  }
}
Execute via CLI 
$ agentxray diagnose scenario.json
# Outputs structured terminal card with exit code 0
